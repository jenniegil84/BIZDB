# 설치안내 — 세미나 신청 페이지 연결하기

- 버전: v00.01 (2026-11-12)

순서대로 4단계입니다. **각 단계가 끝나면 알려주세요.** 다음 단계에서 막히는 부분을 같이 확인합니다.

---

## 1단계. Flow 준비 (약 5분)

1. Flow에서 세미나 신청 알림용 **새 프로젝트**를 만듭니다. 알림을 받을 담당자를 참여자로 초대합니다.
2. 만든 프로젝트 상단의 **점 세 개(⋯) 버튼**을 눌러 **프로젝트 번호**를 확인하고 메모합니다.
3. Flow 개발자 포털의 **「키관리」** 페이지에서 **API Key**를 발급받아 메모합니다.
   - 이 키로 등록된 업무는 **키를 발급한 사람 이름**으로 올라갑니다.
   - 키는 비밀번호처럼 다룹니다. 채팅이나 문서에 붙여넣지 말고 2단계의 "스크립트 속성"에만 넣습니다.

---

## 2단계. 구글 시트 + 접수 프로그램(Apps Script) (약 10분)

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. 이름 예: `세미나 신청내역`
2. 상단 메뉴 **확장 프로그램 → Apps Script**를 누릅니다.
3. 왼쪽 `Code.gs`에 원래 있던 내용을 모두 지웁니다. 저장소의 `세미나 신청/apps-script/Code.gs` 내용을 **전부 복사해 붙여넣고** 💾 저장합니다.
4. 왼쪽 **⚙ 프로젝트 설정** → 맨 아래 **스크립트 속성 추가**를 누르고 아래 값을 넣습니다.

   | 속성 | 값 |
   |---|---|
   | `FLOW_API_KEY` | 1단계에서 받은 API Key |
   | `FLOW_PROJECT_ID` | 1단계에서 확인한 프로젝트 번호 |
   | `FLOW_WORKERS` (선택) | 업무 담당자 Flow 아이디(이메일). 여러 명이면 쉼표로 구분 |

5. 편집기로 돌아와 위쪽 함수 선택 칸에서 **`setup`**을 고르고 **▶ 실행**을 누릅니다.
   - 처음 실행하면 **권한 허용** 창이 뜹니다. 본인 계정을 선택합니다.
   - "Google에서 확인하지 않은 앱" 경고가 뜨면 **고급 → (프로젝트명)(으)로 이동 → 허용**을 누릅니다. 내가 만든 프로그램이라 뜨는 정상 경고입니다.
   - 시트에 **「신청내역」 탭과 머리줄**이 생기면 성공입니다.
6. 함수 선택 칸에서 **`testFlow`**를 고르고 **▶ 실행**합니다.
   - Flow 프로젝트에 **「[세미나 신청] … 연결 확인용 테스트」 업무**가 생기면 성공입니다. 이 업무는 지워도 됩니다.
7. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(⚙): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
8. **웹 앱 URL을 Claude에게 알려주세요.** 이 주소는 공개돼도 괜찮습니다. 페이지에 넣는 일은 Claude가 합니다.

> 나중에 Code.gs를 고치면 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.

## 3단계. Netlify 새 사이트 연결 (약 5분)

Claude가 작업물을 `main`에 반영해도 될지 먼저 여쭤봅니다. 승인하신 뒤에 진행하세요.

1. Netlify에 로그인한 뒤 **Add new site → Import an existing project**를 누릅니다.
2. **GitHub**를 선택하고 저장소 **BIZDB**를 고릅니다.
3. 설정 화면에서 아래처럼 입력합니다.
   - Branch to deploy: `main`
   - Base directory: (비워 둠)
   - Build command: (비워 둠)
   - Publish directory: `세미나 신청/site`
4. **Deploy**를 누릅니다.
5. **Site configuration → Change site name**에서 주소를 정합니다. 예: `semo-seminar` → `semo-seminar.netlify.app`

## 4단계. 실제 신청 테스트

1. 새 주소로 들어가 본인 정보로 신청합니다.
2. 아래 3가지를 확인합니다.
   - [ ] 화면에 「신청이 완료되었습니다」가 표시된다
   - [ ] 구글 시트 「신청내역」에 한 줄이 추가되고, 「Flow 등록」 칸이 **완료**로 바뀐다
   - [ ] Flow 세미나 프로젝트에 업무가 생기고 알림이 온다
3. 테스트 줄은 시트에서 지워도 됩니다.

「Flow 등록」 칸에 **실패(…)**나 **미설정**이 보이면 그 문구를 그대로 알려주세요.
