# PROJECT_CONTEXT.md — 세미나 신청 페이지

> 이 프로젝트의 현재 상태·확정 정책·변경 이력을 쌓는 살아있는 문서.

- 버전: v00.01
- 최초 작성일: 2026-11-12

## 1. 목적

외부 고객(세무사무소)이 **세모리포트 사용법 교육 세미나**를 신청하는 공개 랜딩페이지.
신청은 구글 시트에 쌓이고, 동시에 Flow 세미나 프로젝트에 업무로 등록되어 담당자가 알림을 받는다.

## 2. 확정 사항 (2026-11-12 사용자 확정)

| 항목 | 내용 |
|---|---|
| 대상 | 외부 고객용 공개 페이지(목업 아님) |
| 세미나 | 세모리포트 사용법 교육 세미나 |
| 일정 | 온라인 · **매월 셋째 주 수요일** |
| 정원 / 마감 | 제한 없음 / 신청마감일 없음 |
| 신청 항목 | 이름 · 연락처 · 이메일 · 사무소명 · 듣고 싶은 내용 |
| 문의처 | https://qe398.channel.io |
| 신청 저장 | 구글 시트 |
| 알림 | Flow — **세미나용 프로젝트를 새로 만든다** |
| 호스팅 | **새 Netlify 사이트**(기존 대시보드 bizdb 와 분리) |

## 3. 구현 시 정한 것 (사용자 확인 필요 표시 포함)

- 신청자가 **다가오는 3개 회차 중 하나를 고른다**(당일까지 신청 가능, 한국 시간 기준).
- 같은 이메일로 같은 회차를 다시 신청하면 새로 쌓지 않고 「이미 신청된 회차」로 안내.
- 「듣고 싶은 내용」은 선택 항목, 나머지는 필수.
- 개인정보 수집·이용 동의(필수) — 보유 기간 문구 「세미나 안내 목적 달성 후 지체 없이 파기」는 **확인 필요**(사내 개인정보 처리방침과 맞출 것).
- Flow 등록이 실패해도 신청은 시트에 남고, 시트 「Flow 등록」 칸에 실패 사유가 기록된다.

## 4. 미완료 작업

| 항목 | 상태 |
|---|---|
| 세미나 **시간**(몇 시~몇 시) | 미정 — 정해지면 `SEMINAR.time` 입력, 그 전까지 화면에 시간 표시 안 함 |
| **접속 방법**(줌 링크 등)·신청 후 안내 방식 | 미정 — 완료 화면에 접속 안내 문구 없음 |
| **로고** | 구글 드라이브 연결 실패로 못 가져옴 — 지금은 「세」 배지 + 글자. 파일 받으면 `site/` 에 넣고 `SEMINAR.logoUrl` 입력 |
| 벤치마크(wemembers) 반영 | 사이트 접속이 막혀 미반영 — 캡처 받으면 검토 |
| Flow 세미나 프로젝트 생성 · API Key 발급 | 사용자 진행 필요(설치안내.md) |
| 구글 시트 + Apps Script 설치 | 사용자 진행 필요(설치안내.md) |
| Netlify 새 사이트 연결 | 사용자 진행 필요 · `main` 반영 승인 후 |
