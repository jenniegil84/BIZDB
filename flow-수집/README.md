# flow-수집 — Flow 업무 데이터 주간 자동 수집

> 매주 목요일 아침, Flow 프로젝트에서 **지난 한 주(목~수)에 등록·수정된 업무**를 자동으로
> 수집해 이 폴더에 쌓는다. 주간회의(목요일) 전에 그 주 자료가 준비되게 하는 것이 목적이다.

- 버전: v00.01
- 최초 작성일: 2026-10-21
- 업데이트 이력:
  - v00.01 (2026-10-21): 최초 작성. 2026-10-15~21 1주치 시범 수집분 포함.

---

## 1. 왜 이 폴더가 저장소 **루트**에 있나 (중요)

Netlify는 `사업센터 대시보드/` 폴더를 그대로 서비스한다. **그 폴더에 넣은 파일은 누구나
주소만 알면 받을 수 있다.** 여기 쌓이는 자료에는 사무소명·담당자·(앞으로) 사업자번호가
들어가므로 **배포 대상 밖인 저장소 루트**에 둔다. 이 폴더를 `사업센터 대시보드/` 안으로
옮기지 말 것.

## 2. 수집 대상

| 항목 | 값 |
|---|---|
| 프로젝트 | `[세모R] 세무사무소 신청 관리` (projectId **1834962**, 총 1,904건) |
| 주기 | 매주 목요일 07:47 (KST) |
| 범위 | **지난 목요일 ~ 어제(수요일)** 에 **등록**된 업무 |
| 파일명 | `주간/1834962_YYYYMMDD-YYYYMMDD.json` |

전량(1,904건)을 매주 다시 긁지 않는다 — 업무번호·내용은 **건별 조회**가 필요해 전량 수집이
불가능하다. 주 10건 안팎의 **증분**만 가져와 쌓는다.

## 3. 한 건에 담기는 것

업무번호 · 등록일 · 수정일 · 구분 · 사무소 · 유입경로 · **유입코드** · **추천인코드** ·
상태 · 담당 · 거래처수 · 담당자수 · 요금제 · 개업일자 · 가입내역(세모R/인사이트/위멤버스/링크패스) ·
댓글수 · Flow 링크.

## 4. 지금 **못 가져오는 것** — 사업자번호 · 전화번호

Flow 연결 통로(MCP)가 개인정보로 판단해 `<<biz_reg_no-0>>` · `<<phone-0>>` 로 **가린 채**
내려준다. 저장소 쪽에서 풀 수 있는 설정이 아니다. 그래서 `"사업자번호": null` 로 둔다
(없는 값을 지어내지 않는다 — 공통 규칙 7번).

**사무소명으로 마스터에서 되찾는 방법은 쓰지 않는다.** 2026-10-15~21 1주치로 실측한 결과:

| 방식 | 결과 |
|---|---|
| 사무소명 **정확일치** | 5 / 9 |
| 부분일치까지 포함 | 6 / 9 |
| 못 찾음 | 3 / 9 — `세무회계 태범` · `오름세무회계` · `세무회계 태린` |

못 찾은 3건은 전부 **아직 마스터에 없는 신규 도입문의**다. 즉 **사업자번호가 가장 필요한
쪽이 구조적으로 안 채워진다.** 부분일치(`세정회계법인 강성일회계사님팀`)도 같은 법인에
팀이 여럿이라 틀린 번호를 넣을 위험이 있다. 그래서 채우지 않고 비워 둔다.

### 사업자번호를 받으려면 (둘 다 필요)

1. **flow.team 아웃바운드 허용** — 지금은 실행 환경의 네트워크 정책이 막고 있다(403).
   클라우드 환경 설정 → Edit → Network access 에서 접근 수준을 넓히거나
   Allowed domains 에 `flow.team` 을 추가한다(Allow package managers 는 켠 채로).
   https://code.claude.com/docs/en/cloud-environments#network-access
2. **Flow API Key** — 환경 비밀값(Environment secrets)으로 등록한다.

둘이 갖춰지면 MCP 대신 Flow API를 직접 불러 **가림 없이** 받는다. 그때 이 문서의 4번을
고쳐 쓴다.

## 5. 아직 하지 않은 것

여기 쌓인 자료를 **대시보드 화면이 읽지는 않는다.** 수집이 몇 주 안정적으로 도는 것을
확인한 뒤, 어느 화면에 어떻게 붙일지 정해서 `index.html` 에 연결한다(그때는 배포가 필요하므로
사용자 확인을 받는다).

지금 실적 관리·도입문의 화면이 쓰는 자료는 **종전대로 Tasklist 엑셀 업로드**다. 이 수집은
그것을 아직 대체하지 않는다.
